# apps/web — front end

React 19 + Vite + TanStack Router (file-based routing, per-route code splitting) + TanStack Query.
Runs **locally only** and calls the API deployed on API Gateway.

## Run

From the repo root (after `mise install` and `pnpm install`):

```sh
cp apps/web/.env.example apps/web/.env.local   # then set VITE_API_URL
pnpm --filter @election/web dev                # http://localhost:5173
```

## `VITE_API_URL`

- API base URL, stage included: `https://<api-id>.execute-api.eu-west-1.amazonaws.com/dev`.
- Goes in `.env.local` (git-ignored via `*.local`), never hardcoded.
- Inlined by Vite at build time (`import.meta.env`): it ends up **in plain text in the bundle**, so never put a secret in it.
- Missing → the app fails at startup (`src/lib/config.ts`), on purpose.
- CORS: the Lambda allows one exact origin (`CORS_ORIGIN`, e.g. `http://localhost:5173`). Another port → requests blocked by the browser.

## Test

```sh
pnpm --filter @election/web test        # Vitest + jsdom + Testing Library
pnpm --filter @election/web typecheck   # tsc -b
pnpm --filter @election/web build       # tsc -b && vite build → dist/
```

Tests never hit the API: the `src/api/*` module is mocked (`vi.mock`).
`src/routeTree.gen.ts` is generated by the TanStack Router plugin (dev and build) and **committed**: without it, `typecheck` fails in CI.

## Native binaries (Intel Mac dev machine)

Several dependencies ship one binary per platform, picked by pnpm at install time:

| Package | Used by | Intel Mac binary |
| --- | --- | --- |
| `@rolldown/binding-*` | Vite 8 (bundler) | `darwin-x64` |
| `lightningcss-*` | Vite (CSS) | `darwin-x64` |
| `@esbuild/*` | Vite/Vitest tooling (via `tsx`) | `darwin-x64` |
| `@biomejs/cli-*` | lint/format | `darwin-x64` |
| `fsevents` | file watcher | macOS only, optional |

Watch out:

- Never copy `node_modules` between machines (Intel Mac ↔ Linux x64 CI): run `pnpm install` again.
- `Cannot find module '@rolldown/binding-darwin-x64'` → incomplete install (optional deps skipped): `rm -rf node_modules && pnpm install`.
- Any new dependency with a native binary must exist for `darwin-x64` and `linux-x64` (CI).

## Not yet (accepted debt)

Intentionally missing for now, to add when a screen needs it:

- **shadcn/ui**: no design system; plain HTML.
- **TanStack Form**: no forms yet (create election, cast vote).
- **Zustand**: no shared client state; server state goes through TanStack Query.
- **Auth**: none (magic link, session). The API is called anonymously.
- **Deployment**: no hosting (S3 + CloudFront); local only, out of current scope.
